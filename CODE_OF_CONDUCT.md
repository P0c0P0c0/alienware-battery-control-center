# Code of Conduct

Treat other contributors with respect. Give specific, constructive feedback and accept good-faith corrections. Protect personal information and make room for different experience levels. Harassment, threats, discriminatory conduct and disclosure of personal information are unacceptable.

Keep conduct reports confidential. A private conduct-reporting contact needs owner approval before public publication. GitHub Private Vulnerability Reporting is for security vulnerabilities. Maintainers may remove harmful material, restrict participation or ask for corrective action.
